# My Market App

## Описание проекта

**My Market App** — веб-приложение интернет-магазина, разработанное на Java с использованием Spring Boot,
с функциями поиска/сортировки/пангинации списка товаров, формирования корзины покупок и оформления заказов.

### Функционал приложения:

- просмотр списка товаров;
- поиск товары по названию и описанию;
- сортировка товаров;
- просмотр страницы отдельного товара;
- добавление товаров в корзину;
- удаление товаров из корзины;
- оформление заказов;
- хранить данные о товарах в PostgreSQL или H2 (в режиме тестирования);
- запускать приложение в Docker-контейнере.

### Используемые технологии

- язык разработки: **Java 21**;
- JDK: **Eclipse Temurin 21.0.7**;
- система сборки и управления зависимостями: **Gradle**;
- фреймворк **Spring Boot Framework 3.5.14**;
- фреймворк **Spring Data JPA** / **Hibernate**;
- хранение данных (рабочий/тестовый режим): **PostgreSQL** / **H2**;
- фреймворк для тестирования приложения: **JUnit 5.10.2**;
- html-шаблоны: **Thymeleaf**;
- контейнеризация: **Docker**, **Docker Compose**.

### Структура API

- `GET /` — получить главную страницу со списком товаров;
- `GET /items?search=&sort=&pageNumber=&pageSize=` — получить список товаров по поиску, сортировке и пагинации;
- `POST /items?id=&action=&search=&sort=&pageNumber=&pageSize=` — изменить количество товара в корзине из каталога;
- `GET /items/{itemId}` — получить страницу товара по ID;
- `POST /items/{itemId}?action=` — изменить количество товара в корзине со страницы товара;
- `GET /cart/items` — получить содержимое корзины;
- `POST /cart/items?id=&action=` — изменить количество товара в корзине со страницы корзины;
- `GET /orders` — получить список заказов;
- `GET /orders/{orderId}?newOrder=` — получить заказ по ID;
- `POST /buy` — оформить заказ из текущей корзины.

### Профили и конфигурация приложения

Приложение поддерживает несколько профилей Spring Boot для различных сценариев запуска.

#### application.properties

Основной файл конфигурации приложения.

Используется для локального запуска приложения и содержит общие настройки:
- имя приложения;
- настройки подключения к PostgreSQL;
- настройки Hibernate и JPA;
- параметры логирования.

#### application-dev.properties

Профиль для локальной разработки.

Активируется параметром:

```bash
-Dspring.profiles.active=dev
```
или
```bash
./gradlew bootRun --args='--spring.profiles.active=dev'
```

Может содержать:
- настройки локальной базы данных;
- дополнительные параметры логирования;
- настройки для разработки и отладки.

#### application-docker.properties

Профиль для запуска приложения в Docker.

Активируется автоматически через переменную окружения:
```yaml
environment:
  SPRING_PROFILES_ACTIVE: docker
```

Используется для подключения к PostgreSQL-контейнеру внутри сети Docker:
```properties
spring.datasource.url=jdbc:postgresql://postgres:5432/my-market-app
```
где `postgres` — имя сервиса базы данных в `docker-compose.yaml`.

#### Используемые профили

| Профиль | Назначение |
|----------|-----------|
| default | локальный запуск без указания профиля |
| dev | локальная разработка |
| docker | запуск приложения в Docker-контейнерах |

#### Проверка активного профиля

При запуске приложения в логах Spring Boot отображается активный профиль:
```text
The following 1 profile is active: "docker"
```
или
```text
The following 1 profile is active: "dev"
```

## Запуск приложения

### Локально через терминал

1. Сборка исполняемого jar-файла:

- перейти в корневую папку проекта `my-market-app`;
- выполнить команду в терминале:
    - для Unix-систем: ```./gradlew clean build```;
    - для Windows: ```gradlew.bat clean build```;
- после успешной сборки JAR-файл будет находиться в директории: `build/libs/`.

2. Запуск тестов:

- перейти в корневую папку проекта `my-market-app`;
- выполнить команду в терминале:
    - для Unix-систем: ```./gradlew clean test```;
    - для Windows: ```gradlew.bat clean test```.

3. Запуск PostgreSQL в Docker-контейнере: ```docker compose -f docker-compose.dev.yml up -d```

4. Запуск приложения с профилем `dev`:

- перейти в папку с собранным файлом: ```cd build/libs```;
- запустить приложение: ```java -Dspring.profiles.active=dev -jar my-market-app-0.0.1-SNAPSHOT.jar```;
- или запустить напрямую через Gradle:
    - для Unix-систем: ```./gradlew bootRun --args='--spring.profiles.active=dev'```;
    - для Windows: ```./gradlew.bat bootRun --args='--spring.profiles.active=dev'```.
   
5. После запуска приложение будет доступно по адресу: http://localhost:8080.

### В Docker

1. Контейнеры приложения и PostgreSQL запускаются с помощью `docker-compose.yaml`:

- сборка образа приложения и запуск контейнеров: ```docker compose up -d --build```;
- повторный запуск без пересборки: ```docker compose up -d```;
- остановка контейнеров: ```docker compose down```;
- удаление контейнеров и томов БД: ```docker compose down -v```.

2. После запуска приложение будет доступно по адресу: http://localhost:8080.


### Наполнение базы данных

При запуске приложения выполняется инициализация тестовых данных через `CommandLineRunner` в классе `MyMarketAppApplication`.

В базу автоматически добавляются:
- товары;
- элементы корзины;
- тестовые заказы.

Данные пересоздаются при каждом запуске приложения.
